# Pedro Brauner

Content and creative strategist in esports and gaming, based in Lima. I build my own tools and apps when I need them.

## Things I've built

- **[Foiled](https://foiled.gg)**: a Magic: The Gathering app with a public user base, built on Supabase. The code is private.
- **[lasopapodcast.com](https://lasopapodcast.com)**: the site and live-show system for La Sopa, Peru's leading Spanish-language Dota 2 and esports podcast: fan voting, giveaways, overlays and live chat on air.
- **[cs2-demo-tool](https://github.com/pebrauner/cs2-demo-tool)**: a local web app for CS2 demo files, with a replay viewer, position heatmaps and an economy panel.
- **[mapa-tiendas](https://github.com/pebrauner/mapa-tiendas)**: a database of retail stores in Peru and a map generator for presentations.
- Plus a bunch of work-related stuff that I can't show here for obvious reasons.

More about my work at [pedrobrauner.com](https://pedrobrauner.com).
